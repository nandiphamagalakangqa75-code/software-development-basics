## Programs Included

### Conditions

This program demonstrates how `if`, `elif`, and `else` statements are used to make decisions based on a user's input.

For example, the program can check a user's age and determine whether they are an adult or a minor.

### Loops

This program demonstrates how loops are used to repeat instructions.

For example, a `for` loop can be used to display numbers from 1 to 10.

### Number Checker

This program uses conditions to check whether a number is positive, negative, or zero.

### Simple Calculator

This program uses conditions to perform basic mathematical operations such as addition, subtraction, multiplication, and division.
